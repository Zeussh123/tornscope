PLANNER - "Use my position" (wiring into the Worker dashboard)

Rule asked: if we are already flying, the next take-off is only possible after landing + 30 s minimum (time to open the travel page).
Module: site-modules/planner-position.js (tested). In the Worker's DASHBOARD_HTML script:

1. Source of the position
   a) "Use my position" button -> GET /api/me/travel (new). The Worker decrypts the member's stored key (decryptUserKey(env, account.id, row.enc)),
      calls tornKeyRequest("user/", "travel", key) and returns { state, country, direction, landAt }:
        time_left > 0            -> state 'flying', landAt = now + time_left, direction 'return' if destination is Torn, else 'out'
        destination != Torn      -> state 'abroad', country = destination
        else                     -> state 'torn'
      No stored key -> answer 404 and the page shows the manual form below. Rate-limit it (registerFailure bucket "mytravel:<id>", 1 per 10 s).
   b) Manual: three fields "I am: in Torn / flying home / flying to X / in X" + "lands at HH:MM".
   Keep RADAR_PLAN.pos = {...} (saved in localStorage ts_plan like the other settings).

2. Maths
   - const first = TornScopePlanner.earliestDeparture(pos, now, c => travelSec[c][P.type]);
   - planRows(ST, P, now) -> TornScopePlanner.planRows(ST, P, now, first.at)   (stock on landing is computed for the real take-off time)
   - dayPlan(rows, P, now)  -> TornScopePlanner.dayPlan(rows, P, now, first.at)  (first trip never before first.at, then back + 30 s between trips)
   - "Take off at" column: shows departAt, and a small hint "after your landing (HH:MM:SS)" when first.at > now.
   - Show a banner above the list: "You are flying home, landing 09:14:22 -> earliest take-off 09:14:52".

3. Edge cases handled by the module
   - flying OUT: you must land, then fly back (return time of that country) before leaving from Torn; the banner says so.
   - landing time already past -> treated as now.
   - an item that would be sold out by the later landing becomes 'late' (red) instead of 'Now'.
