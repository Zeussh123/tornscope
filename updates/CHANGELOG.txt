------------------------------------------------------------
v3.26.0 (Worker) / v3.6 (Script)  -  2026-10-24  -  "No more jumping"
------------------------------------------------------------
FIXED
 - Dashboard: the automatic refresh (every 60 s on Overview/Targets, 30 s on Radar/War)
   threw the page back to the top when you were scrolled down. The page is now rebuilt
   with its height frozen and the scroll position restored (Overview, Targets, Radar, War list).
 - Overlay (script): the target list was rewritten every second even when nothing changed,
   which reset its scroll position. It is now only redrawn when the content changes.
 - Script version strings were inconsistent (header 3.5 / VERSION 3.4); all say 3.6 now.

NEW / UI
 - Dashboard sidebar: the emoji/glyph icons are replaced by clean line icons (SVG) that follow
   the theme and light up in the accent colour on hover / active page.

NOTES
 - Not changed: data, API, database schema, Premium logic.
