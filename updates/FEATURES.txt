TORNSCOPE - FEATURES AND IDEAS BACKLOG
======================================

CURRENT FEATURES
- Target tracking: flights, landings, abroad, hospital, jail, with alarm + notifications
- Aircraft guess, flight history, statistics, countries view, alerts
- War mode (enemy faction watch, "land together" calculator)
- Radar (beta), Premium server-side tracking, dark/light theme
- Works on Tampermonkey and Torn PDA

HOW TO UPDATE THE SITE
1. Edit site/dashboard.html
2. node tools/build-worker.mjs <previous-worker>.mjs site/dashboard.html worker<new>.mjs <new version>
3. Deploy the new worker file.
